# Retail Sales Analysis & KPI Dashboard 

## 📊 Overvie
This project analyzes pizza sales data using *Microsoft Excel* to uncover key business insights such as top-selling products, revenue trends, and customer preferences.  
It helps identify performance metrics that can guide better decision-making for sales improvement.

---

## 📁 Project Files
- *Pizza Sales Project File.xlsx* – Main dashboard and data analysis.
- *Data Model - Pizza Sales Project.xlsx* – Supporting dataset used for pivot tables and calculations.

---

## 🧠 Key Insights
- Identified *top-selling pizzas* and categories.
- Analyzed *sales by day and time* to find peak business hours.
- Discovered *best-performing pizza sizes*.
- Highlighted *total revenue and order trends*.
- Created an *interactive Excel dashboard* for visualization.

## 🚀 How to Use
1. Download the .xlsx files from this repository.
2. Open in *Microsoft Excel (2016 or later)*.
3. Explore the *Dashboard sheet* to interact with the visualizations.
